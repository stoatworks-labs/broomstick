# Broomstick

A witch on a broomstick, a forest at night, and a great many trees that were
there first. Press Space, click or tap to fly. Thread her between the tree that
grows up from the forest floor and the one hanging down from the canopy. Each
pair you get past is a point. Touch a branch or the ground and the run is over.
The cat riding on the back is along for the view.

It runs in a browser, on a phone or a desktop, and is served as a static
Cloudflare Worker.

## The artwork

The witch, the dead trees, the bats, the jack-o'-lanterns and the gravestones
are [Test Card](https://github.com/stoatworks-labs/test-card)'s Halloween
drawings, the same ones in its spooky forest and haunted house patterns. They
are pure functions that return polygons, so they come across as source
(`src/art/`, generated by `scripts/sync-art.mjs`) rather than as pictures. The
sky, the moon, the mist and the eyes in the wood are painted the way Test
Card's spooky forest paints them, palette included.

## Controls

| Input | Does |
| --- | --- |
| Space, ↑, W, Enter, click or tap | Flap. Also starts a run and carries on after a pause |
| P or Esc | Pause |
| M, or the speaker button | Sound on or off |

The game pauses itself when the tab is hidden, the window loses focus, or a
phone is turned on its side.

## How it decides what you hit

Every solid branch of a tree is a polygon from Test Card's drawing, and the
witch is fifteen points on hers: hat, head, nose, body, hand, boot, the front
of the broom and the brush. Her cloak, her hair, the tip of her hat and the cat
are scenery. The outermost twigs of each tree are drawn but forgiven; they
reach a little way into the gap and no further. The tests fly a pilot through
fifty trees on several seeds to show every gap can be flown.

## Running it

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # the rules, the trees, and the pilot
npm run build        # dist/, what the Worker serves
```

Picking up changed artwork from Test Card (its committed `main`):

```bash
npm run sync-art     # rewrite src/art/
npm run check-art    # fail if src/art/ has drifted
```
